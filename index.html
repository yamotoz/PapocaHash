01 / PYTHON

A precisão do laço.

Percorre cada candidato do bloco e encerra ao encontrar uma correspondência. Um núcleo direto, distribuído entre processos para explorar a CPU.

Iterativo5 linhas de núcleoO(n × H)
backend/kernels.pyiterative
def iterative(words, check):
    # Enumerar o bloco evita índice/decodificação no caminho crítico.
    for index, word in enumerate(words):
        if check(word):
            return index
    return None
Sequência simples. Saída imediata.01
02 / PYTHON

O equilíbrio da divisão.

Divide o bloco em duas partes e visita os candidatos na mesma ordem. A divisão equilibrada mantém a profundidade da recursão pequena, mesmo em blocos grandes.

Recursivo9 linhas de núcleoPilha O(log b)
backend/kernels.pyrecursive
def recursive(words, check, lo=0, hi=None):
    hi = len(words) if hi is None else hi
    if lo >= hi:
        return None
    if hi - lo == 1:
        return lo if check(words[lo]) else None
    # Divisão equilibrada: todos os candidatos, pilha O(log bloco).
    mid = (lo + hi) // 2
    found = recursive(words, check, lo, mid)
    return found if found is not None else recursive(words, check, mid, hi)
Dividir o bloco. Preservar a ordem.02
03 / RUST

A força das fatias.

Percorre os bytes do bloco sem copiar cada palavra. O compilador especializa o verificador; ao redor deste núcleo, o pool Rayon distribui blocos entre as threads.

Threads Rayon3 linhas de núcleoO(n × H)
rust-engine/src/kernel.rsfind
/// A closure monomorfizada permite ao compilador integrar o hash ao laço.
pub fn find<F: FnMut(&[u8]) -> bool>(block: &[u8], verify: F) -> Option<usize> {
    block.split(|&byte| byte == b'\n').filter(|word| !word.is_empty()).position(verify)
}
